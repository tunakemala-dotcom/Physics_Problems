# Task 06 – Instrument Precision

## Problem Statement

A digital thermometer reads $25.4^\circ\text{C}$. Assuming the uncertainty is half the value of the last digit, what is the absolute uncertainty of this measurement?

## Theory

For digital instruments, the reading error is often taken as either the smallest division (resolution) or half of the smallest division, depending on the convention used. The problem specifies using half the value of the last significant digit.

## Step-by-Step Solution

Identify the position of the last digit in the reading $25.4^\circ\text{C}$. The digit '4' is in the tenths place.

Therefore, the smallest unit (resolution) is $0.1^\circ\text{C}$.

Calculate the absolute uncertainty according to the given rule:

$$
\Delta T = \frac{0.1}{2} = 0.05^\circ\text{C}
$$

## Final Result

The absolute uncertainty of this measurement is $\pm 0.05^\circ\text{C}$.

## Interpretation

This implies the true temperature lies anywhere within the interval $[25.35^\circ\text{C}, 25.45^\circ\text{C}]$, as any value within this range would mathematically round to the digital display of $25.4$.
